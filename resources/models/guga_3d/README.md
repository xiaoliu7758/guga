# Guga Blender avatar

- `guga.blend` — Blender 4.2 source: editable meshes/materials, packed original texture, rigid skinning, rig, animation clips, reference image, camera and lighting.
- `guga.glb` — exchange model, 1 skin, 5 animation clips. This is a custom rig, not a VRM humanoid.
- `avatar.mesh.json.gz` — runtime mesh for `ui/avatar_renderer.py`; X right, Y up, Z toward viewer.
- `blender-preview.png` — Blender render, distinct from the Qt runtime lighting.

Generated by `tools/build_blender_avatar.py` from local Guga expression artwork. No third-party character meshes were downloaded. Rights in the original artwork remain with their original rights holders; repository/code licenses do not automatically license character art.

The runtime consumes the compact mesh, so Blender is not required on the recipient's machine. Hand edits to the `.blend` do not update the runtime mesh automatically. Keep a separate copy before running the procedural rebuild script, which replaces its generated outputs.

See `docs/desktop-avatar-research-20261026.md` for references, test results, current limitations and the authoring workflow.

The default pet appearance remains the original illustration. The Blender preview now projects the complete original hood/hair/face onto a curved shell with a back volume, preserving authored facial details. It is a hybrid 2.5D/3D preview, not a fully sculpted production head; the thick side/back shell still needs manual sculpting at large view angles.
