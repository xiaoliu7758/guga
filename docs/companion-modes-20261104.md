# 咕嘎常用与唤醒形态优化

版本：`2026-11-04.companion-modes.1`，2026-11-04。

## 最终行为

| 场景 | 行为 |
| --- | --- |
| 常用形态 | 默认空闲10秒后主动聊一到两句；结合真实日期、当天公开新闻摘要、真实喜好、职业和近期对话，轮换新闻、梗、生活观察与项目话题，避免重复盘问。 |
| 用户回应 | 从用户明确的第一人称表达，以及对偏好、职业问题的简短回答中提取长期资料。相同职业及同一偏好的纠正替换旧资料，成员记忆保持隔离。 |
| 纯问答 | 独立问答线程查询公开搜索摘要，再结合相关资料、对话和用户记忆回答；不启动桌面执行器，不打开浏览器抢焦点。问候、情绪回应和个人喜好等闲聊不做无意义搜索。 |
| 问答表达 | 等待时轮换“让本鹅想一想”“这道问题倒是有点意思”等短台词；清理思考标签、Markdown标题、加粗和错误的表情分隔符。资料不足时不得编造搜索成功。 |
| 气泡回答 | 桌面只显示一个咕嘎气泡；气泡底部提供取消、动态波形和按住说话按钮，按住录音、松开发送，回答后重新开始主动聊天节拍。 |
| 唤醒形态 | “唤醒”开启长对话，“结束长对话”退出；保留长对话默认启动屏幕辅助，指令明确禁止反问“共享屏幕开了吗”。 |
| 简单电脑任务 | 保留现有快速命令及本地视觉执行路径；共享画面只提供观察依据，实际操作后仍需读取回执。 |
| 复杂任务 | 保留现有DSH工程任务路由；本地进度计时器每30秒结合真实回执报告进展、已知困难和简明下一步判断。 |
| 任务期间聊天 | 用户的闲聊和知识问题进入独立前台问答通道。真正的“改成……”“加上……”等追加要求仍交给当前执行器；问答完成不能清除后台任务状态。 |

主动聊天默认间隔为10秒，复杂任务进度仍为30秒；两者不是远端模型的完成时限。用户说话、正在播音、录音、回答或播放音乐时等待自然停顿，不叠音。主动搭话生成后再次核对成员、会话和最近用户活动，过期结果直接丢弃。新闻搜索默认每15分钟更新一次，10秒聊天会轮换引用缓存中的新话题；没有可引用资料时不会假装刚看到新闻。

## 记忆与搜索边界

`AgentMemoryStore.add_dialogue`统一处理文字、短语音和长对话入口；自动记忆保存在现有SQLite的`agent_facts`中。提取采用保守的本地规则，不根据助手回复、截图、假设、引用台词或问题猜测用户背景。密钥等内容不能成为自动用户档案。保留“查看我的记忆”“忘记记忆 编号”等已有命令。

实时语音在用户新话语后刷新可用记忆，屏幕会话同步同时感知记忆变化，使新信息在本次通话可用。自动提取覆盖常见表达，不保证理解全部隐含表述；复杂的明确要求仍可用“记住：……”保存。

问答复用现有Bing公开搜索，不引入新依赖或搜索账户。只把本轮问题发送给搜索服务，不把长期记忆拼进搜索关键词；当前聊天服务仍按原有配置接收对话及选取的记忆。只展示回答实际引用的真实搜索条目，朗读不念来源列表和网址。搜索结果有可能泛化、受限或为空；来源是摘要而非已核实的全文，不能据此承诺豆包同等质量。

长对话继续使用原有千问音频模型和赠送额度保护，没有升级为付费视频模型。屏幕由既有本机采集与视觉摘要通路辅助；用户明确停止共享后不自动恢复。没有更改系统权限、凭据或付费设置。

## 代码接入

- `core/companion_dialogue.py`：共同口语风格、问答口头禅、输出清理、搜索和追加要求判断。
- `core/chat_answer.py`：独立联网问答、搜索回执注入、来源选择和流式展示。
- `core/agent_memory.py`：明确用户档案提取、纠正覆盖、原有查询与删除能力。
- `core/proactive_conversation.py`：10秒默认间隔、真实日期、新闻缓存、风格轮换、重复拦截和过期结果丢弃。
- `ui/agent_chat.py`：后台任务与前台问答分工、语音结果回传、纯截图问答不误报为已启动任务。
- `core/task_feedback.py`、`core/task_brief.py`、`core/task_speech.py`：30秒进度摘要和播报节流。
- `core/realtime_agent.py`、`core/agent_identity.py`：语音人格、共享默认行为、任务事实与记忆同步。
- `ui/chat_shell.py`、`ui/pet_window.py`：唤醒入口名称、启动后预热常用对话。

新设置键为`multiagent/companion_interval_seconds`，默认10秒，可设10—900秒；`multiagent/news_refresh_minutes`控制新闻缓存刷新，默认15分钟，可设5—120分钟。旧主动搭话键不再决定本轮默认行为。`app_state.assistant_contract.conversation`暴露形态、间隔、新闻缓存和单气泡按住说话能力，便于验收。
