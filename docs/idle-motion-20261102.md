# 自然待机视频动作

用户提供两段豆包生成动画，要求像 DSH Pet 一样进入咕嘎自然常态触发：

- `豆包画图 (1).mp4`：打哈欠、困倦、睡着、醒来。
- `豆包画图.mp4`：双手比心、头顶/身边飘爱心、恢复开心。

两段均为720×960、24fps、约10秒、固定镜头。处理时先缩到480宽，用本地u2netp抠图，再做孔洞修补和原图黄嘴/脚保护。没有补帧、光流、生成式重绘或相邻帧混合；保留原视频239帧、24fps。随后测量每段所有帧的稳定人物轮廓，按统一人物高度重新缩放，统一到与原版咕嘎相同的245×352透明画布、245像素显示宽度和同一脚底基线。实测两段人物中位高度为348和347像素，原版为352像素。

## 触发规则

只在咕嘎空闲、常态/开心表情、没有文字、说话、拖拽、唱歌或任务时，按现有10–22秒随机间隔触发。随机动作中有55%概率选择这两段视频，其他概率保留原画的蹦跳、偷看和傲娇。每次只播放一遍，约10秒后自动回到原画待机。

应用启动后的第一次自然动作在4–8秒内到来，之后间隔12–24秒。运行时发现旧TTS可能留下口型帧，使角色长期停在`talk`并挡住待机；现在连续两秒没有真实说话状态时会清理这个残留口型。右键「🎵 音乐与动作 → 自然动作 · 视频」可主动点播「困倦打盹」和「双手比心」。旧的「摸下巴思考」「挠挠头」「转圈」已从菜单和语音快捷动作中移除。

两段都有自己的权重：比心略高于困倦。说话、拖拽、显式表情、任务开始、唱歌或点击咕嘎都会立即停止当前视频动作。唱歌、任务和聊天行为仍沿用原有实现。

## 资源与内存

正式资源位于 `resources/actions/idle-motion/`，每段239张审核通过的透明帧。启动时只校验帧摘要并建立索引，不预解码全部帧；播放时使用最多36帧的顺序缓存，避免两段共478张大图长期占内存。实测离屏初始化约0.22秒，启动缓存为0帧。

原视频、透明样片和逐帧检查位于 `runtime/idle-action-review-20261102/`。合并预览：`runtime/idle-action-review-20261102/idle-actions-preview.mp4`。用户提供的素材仅在本机使用，没有记录可对外再分发的授权。
