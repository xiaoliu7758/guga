# 咕嘎动态动画 V2

## 问题原因

第一版从 16 张生成关键姿态出发，用 RIFE 对完整人物画面做补帧。不同关键帧的睫毛、头发、锁链和轮廓并非逐像素一致，补帧会把两套边缘叠在一起，形成残影。对透明画面直接平均 alpha 还会产生灰色描边。

## 修正方式

- 使用一对已对齐的高质量全身原画作为单次采样源。
- 头部、身体摆动、左右翅膀、双脚和锁链使用局部形变场运动。
- 每个输出像素只从一张角色图采样一次，不做两张完整人物的 alpha 混合。
- 睁眼和闭眼作为离散姿态切换，只持续短暂节拍，不再生成同时睁闭眼的中间帧。
- 输出 125 帧、25 FPS、5 秒无缝循环。

## 验证

- 125 个透明 PNG，无边缘裁切。
- 脚底基线范围 520–536 像素，差异来自有意的单脚轻踏。
- 安装版实际加载 125 帧通过；加载约 1.2 秒。
- 视觉审核图为 runtime/guga-puppet-dance-20261101/contact-review.png。
- 预览为 resources/actions/joy_sway_dance/preview.gif。
- 构建：`python tools/build_guga_puppet_dance.py --install`。

## 触发

右键“音乐与动作 → 开心摆鳍舞”，语音说“跳舞”，或空闲时概率触发完整一轮。停止跳舞后回退到当前表情。
