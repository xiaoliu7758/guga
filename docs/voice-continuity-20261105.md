# 持续通话修复与验收（2026-11-05）

版本：`2026-11-05.voice-session-owner.1`。

## 问题证据

上一版 `command-session.2` 在用户实际约两分钟通话中记录了 3 次重连，第一次约 3 秒就断开。通话和空闲时限均为 0，不是到时自动结束。断开前曾出现 `invalid_value` 指令拒绝，但日志不足以把全部传输关闭归因于同一个服务端原因。此前一分钟文字注入测试缺少原生语音时序，不能作为持续稳定的证明。

本轮补出的回归在修改前失败：`speech_stopped` 已到、`response.created` 尚未到时，客户端会插入 `response.create` 或背景 `session.update`。本地取消声音会清除生成标记，不能据此判断服务端没有正在创建的回复。[官方原生语音时序](https://www.alibabacloud.com/help/en/model-studio/fun-audiochat-realtime-websocket-api)说明，`server_vad` 会在断句后自动生成回复。

## 改动

- 将“原生语音轮次等待服务端回复”与“正在生成”“回复创建待确认”分别跟踪。断句空档暂停客户端新回复、主动播报和后台配置更新；无效语义轮次释放等待。简单指令从完整转写直接执行，不受这个等待影响。
- 收发协议与命令处理统一到 `guga-realtime` 工作线程；音频回调与界面只投递队列。移除旧发送线程，避免它在退出或报错时写入、关闭后续连接。
- 用短等待检查 socket、TLS 和 WebSocket 已缓存帧，再收包；持续发送音频和响应用户命令。发送超时单独暴露为发送失败，不当作接收空闲而吞掉。
- 移除每 110 分钟主动关闭连接的逻辑。通话和空闲时限默认均为 0；用户显式设置正数仍有效。跨过旧 110 分钟边界的模拟回归在修改前失败、修改后通过。
- 日志按进程分文件并对写入加锁，保留连接序号、失败阶段、运行时长和错误类型，避免并行进程损坏证据；不写音频、转写、提示词或凭据。
- 保留免费额度用尽即停、鉴权错误停止、真实传输故障可中止恢复；不以重连成功冒充连续连接成功。没有改变用户平台、模型、代理或付费设置。

## 持续连接验收

生产语音类直接连接当前实时服务，合成 PCM 经生产音频采集、原生 VAD、原生工具调用和播放回调链路处理。测试持续改变合成屏幕资料，混合主动播报、3 次文字补充、后台等待和一段 54 秒静音。桌面动作执行器隔离返回回执，不操作个人网站或联系人；不用真实麦克风、扬声器，不保存测试录音。

测试设有 600 秒截止，任意非主动断线或服务错误即失败；合格标准还包括足够的原生转写、回复、快捷回执和工作线程退出，不能只保持一个空闲 socket。

| 指标 | 实测 |
| --- | ---: |
| 同一连接持续时长 | 600 秒 |
| 建立的连接数 | 1 |
| 非主动断线 / 重连 | 0 / 0 |
| 服务及协议错误 | 0 |
| 合成片段计划数 | 30（按回调推进，未要求在墙钟截止前全部送达） |
| 原生转写完成 | 26 |
| 回复结束事件 | 56 |
| 快捷指令隔离回执 | 8 |
| 协议写入线程 | 仅 `guga-realtime` |
| 测试工作线程停止 | 是 |

另完成本机 90 秒音频设备检查：输入回调 2249 次、输出 2250 次，输入/输出异常状态均为 0，最大输入间隔 47 ms；静音替换后的 PCM 全零，设备已关闭。该检查不联网、不保存或上传麦克风声音。

## 实际浏览器单步验收

使用独立临时豆包浏览器、自有本机页面，由 UIA 执行动作、Playwright 独立读取页面结果。直接点击输入框、填写、点击按钮、上下滚动均通过。两句合成语音经过真实服务转写后，填写和点击按钮的执行回执分别为 15 / 16 ms，输入值及按钮回调均核验正确，任务模型委派、断线和协议错误均为 0。

以上是完整转写后的热态执行时间；服务端断句到转写另需 188 / 156 ms，且存在默认 600 ms 的断句等待，不是从开始说话计算的总延迟，也不是任意网页的 P95。

首轮语音网页检查未通过：填写时没有目标输入焦点，点击时找不到按钮。原检查在云端合成后未重新聚焦并绑定测试窗口，不能证明操作时仍是自有页面。检查脚本已在语音输入前重新核对窗口、以 UIA 聚焦输入框，并在每个实际动作校验同一个窗口；焦点改变即拒绝执行。补齐这些条件后重新完成 17 项页面核验和语音双指令。原失败结果 `session-owner-browser-final.json` 与通过结果 `session-owner-browser-guarded.json` 均保留在本机 `runtime/browser-response-qa/`。

364 项初轮相关回归及修改后 209 项相关回归通过，覆盖协议所有权、原生轮次空档、跨 110 分钟、发送超时、任务路由、免费保护、浏览器与 UIA。既有 GIF 文件句柄 `ResourceWarning` 未计作本次断言失败。

从 Git 索引导出的无私人配置源码另通过 63 项核心检查；1285 个索引文件通过凭据与发布范围扫描，298 个 Python 文件通过语法检查。源码桌宠已核对双版本标记、完整访问和当前网页单步模式；语音未自动开启。

这证明本轮样本覆盖的持续语音链路通过，不代表数小时真人通话、任意网络或外放回声均已验收。一次回复结束、54 秒静音和用户执行单步指令均不会触发本机主动结束。网络或服务故障恢复仍如实记为断线。
