# 咕嘎空闲性能优化

版本：`2026-11-02.voice-assistant.6`。

## 实测基线

空闲状态：没有长语音、屏幕共享、任务或DSH。原版进程约5.5%单核CPU、180—192MB RSS、38—41线程；两秒采样中曾出现约17%的短时峰值。该CPU并非持续满载，但透明常驻窗口、30FPS精灵重绘和短周期后台检查会造成不必要的唤醒与输入抖动。

## 改动

- 精灵动画由固定30FPS改为自适应：空闲20FPS，说话、手势、任务动画、拖动或表情过渡时恢复30FPS。动画位移和计时改为按真实经过时间推进，避免降帧后动作变慢。
- 视线轮询由12.5Hz降到6.25Hz；全局键盘队列由62.5Hz降到20Hz，快捷键仍保持低延迟。
- 背景亮度采样由15秒改为60秒，窗口隐藏或最小化时跳过，不再频繁截取桌面小块。
- 战棋日志检查空闲时30秒一次；检测到实际对局后提高到8秒。没有对局时不再按8秒持续检查。
- 音乐状态同步定时器仅在播放期间运行。
- 隐藏对话面板预热从启动后2.5秒延后到15秒，降低启动阶段UI、内存和线程集中初始化造成的顿挫；用户提前点击仍按需立即创建。

## 验证边界

- 所有交互与视觉验收需在重启后的同一版本重新采样，才可比较CPU。测试不能替代实际桌面合成器、显卡和窗口遮挡情况。
