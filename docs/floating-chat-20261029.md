# 咕嘎悬浮对话与屏幕问答（2026-10-29）

最新划词实现见 [2026-10-29.4 修正](selection-visual-fix-20261029.md)；独立问答四档、短语音和晴天循环见 [2026-10-29.3 迭代说明](qa-voice-music-20261029.md)。以下保留首轮界面改造记录。

## 使用方式

- 对话：480×650 的紧凑悬浮窗；上方可拖动，右下角可缩放。左上角展开历史对话，右上角提供新对话、置顶、更多、收起、关闭。
- 默认只显示问题与回答。执行记录按钮展开工具记录和进度摘要；没有展示模型的原始隐藏推理。失败会在对话中直接说明，不藏进折叠区。
- 「收起」保留通话和任务；「关闭」结束通话和本窗任务，桌宠继续运行。
- 截图提问：点输入框下方「截图」，或 Ctrl+Alt+A，隐藏咕嘎自身窗口后截取当前显示器，并直接发往当前对话。输入框已有问题时携带该问题，否则默认解释当前画面。不需要框选、也不需要第二次发送。当前任务忙碌时保留为附件并明确提示。
- 外部划词：在其他软件里用左键拖选或双击选词，鼠标旁立即出现「解释」「翻译」短条。无需右键，也不需要先打开咕嘎对话窗。「划词」按钮用于开关这项全局功能。
- 工具条不抢输入焦点，并设置为系统置顶；出现后有限次再次置顶，尽量优先于其他软件稍后弹出的划词条。不能保证压住所有第三方置顶窗，也不强行关闭其他软件的功能。工具条 8 秒后自动收起。
- 优先读取软件提供的选区和所在段落；软件不提供选区时，只有点「解释/翻译」后才复制选中文字，并恢复原剪贴板。复制失败或原窗口已切换时明确提示，不把旧剪贴板当成选区。此分支使用本机识字读取页面上下文。
- 「更多 → 框选截图提问」保留手动框选附件的方式；「更多 → 框选识字解释」或桌宠右键的识字入口用于图片里的文字。Esc / 右键取消框选。Ctrl+Alt+E 仍可直接尝试读取选区。
- 临时解释窗口不创建正式会话，不写入聊天数据库、任务记录或技能记忆。关闭会清空窗口内容；已经发往所配置模型服务的内容不受本地清空控制。
- 桌宠右键 → 咕嘎大小，或对话窗更多 → 咕嘎大小：40%～100%，即时预览并记住设置。目前原尺寸是上限。

## 保留与边界

原画、困倦保持、长语音、DeepSeek 执行工具、快捷打开软件及网站保持原有调用通道。截图传给当前任务的图像输入；不会用本地识字文字冒充看懂图片。

截图仅在当前请求保留图像，正式会话保存问题与答案及截图标记，不把截图数据写入聊天数据库或交接日志。识字临时图片在任务结束时清理。默认截图按钮会发送当前显示器画面；使用框选时只发送选区。

选中文字是否可读取取决于目标软件。UI Automation 读取会跳过密码控件；复制分支也依赖软件允许复制。工具条位于外部软件的选词位置，不修改它们的原生右键菜单。本次没有对所有第三方软件逐一验收。软件若既不提供选区也不允许复制，可使用框选识字。

快捷键注册失败时会在「更多 → 快捷键说明」说明冲突，可继续使用按钮。新版运行核验中两个快捷键都注册成功。
