# 咕嘎学习功能 · 测试清单

> 使用方法：按顺序逐条问咕嘎（或在对话窗口输入），测完在 `[ ]` 里打 `x`。
> 建议按「第 1 轮 → 第 6 轮」顺序走，最快覆盖全部功能。

---

## 第 1 轮 · 截图 / 屏幕学习（核心入口）

- [ ] 1. 「截图分析」 — 预期：框选屏幕后，咕嘎识别并解释画面内容
- [ ] 2. 「解释」选中一段文字 — 预期：弹出解释框，用大白话讲清选中文字
- [ ] 3. 「思维导图」框选区域 — 预期：打开学习工具箱，生成该区域思维导图
- [ ] 4. 「拓展知识」框选区域 — 预期：生成思维导图 + 关联概念/进阶/误区/记忆口诀
- [ ] 5. 右键菜单「🧠 学习工具箱」 — 预期：框选后生成完整学习包（导图/拓展/自测/复习卡）
- [ ] 6. 对话里说「给屏幕截图生成思维导图」 — 预期：直接出导图（不再回复"看不到屏幕"）

## 第 2 轮 · 学习辅导（助教五阶段法）

- [ ] 7. 「我想学 Python 的装饰器」 — 预期：先做学习风格测评（选择题）
- [ ] 8. 「帮我制定一个学习计划，目标是通过英语四级」 — 预期：生成分阶段学习计划
- [ ] 9. 「帮我诊断一下：为什么递归会栈溢出」 — 预期：苏格拉底式引导，逐步追问而非直接给答案
- [ ] 10. 贴一段代码说「帮我 review 这段代码」 — 预期：判分 + 讲解问题点
- [ ] 11. 「生成我的学习周报」 — 预期：汇总本周学习数据，用咕嘎语气汇报

## 第 3 轮 · 错题本 & 复习

- [ ] 12. 自测题答错一题 — 预期：错题自动进入错题本
- [ ] 13. 「我的错题本里有哪些题」 — 预期：列出错题记录
- [ ] 14. 「我有哪些薄弱点」 — 预期：按知识点推荐薄弱环节
- [ ] 15. 问「什么时候提醒我复习」/ 等 15 分钟 — 预期：到期后气泡提醒复习（FSRS 间隔重复）

## 第 4 轮 · 个性化学习

- [ ] 16. 连续快速跳过题目（skip） — 预期：画像向「快进结果型」倾斜
- [ ] 17. 频繁问「能给点提示吗」 — 预期：画像向「畏难求助型」倾斜
- [ ] 18. 让咕嘎讲解一个知识点 — 预期：讲解节奏/措辞随画像变化
- [ ] 19. 「看下我的学习进度」/ 右键「📊 学习进度看板」 — 预期：显示五维雷达图 + 掌握度

## 第 5 轮 · 网页 / 文档转学习卡

- [ ] 20. 「把这个网页转成学习卡」+ 网址 — 预期：解析网页 → 生成学习卡
- [ ] 21. 「把这个 PDF 整理成知识点」 — 预期：PDF 提取文字 → 思维导图/复习卡

## 第 6 轮 · 长回答朗读（修复项）

- [ ] 22. 让咕嘎讲一个超长知识点（>500字）并开启朗读 — 预期：完整念完，不再中途截断
- [ ] 23. 朗读长回答时 — 预期：自动后台保存文档 + 思维导图，气泡提示已存
- [ ] 24. 关闭朗读，问一个超长问题 — 预期：弹窗询问「要不要保存为文档/思维导图」

## 第 7 轮 · 通用学习（学什么教什么 + 语言触发）

- [ ] 25. 直接说「教我英语」 — 预期：自动进入学习模式，温柔讲解英语（无需按数字键 1）
- [ ] 26. 直接说「我想学高中数学」 — 预期：自动进入学习模式，讲解高中数学
- [ ] 27. 直接说「什么是光合作用」 — 预期：自动进入学习模式，用助教人设讲解
- [ ] 28. 直接说「帮我弄懂递归」 — 预期：自动进入学习模式，讲解递归概念
- [ ] 29. 直接说「零基础学日语」 — 预期：自动进入学习模式，从入门开始教
- [ ] 30. 按住说话（语音）说「教我英语」 — 预期：同样自动进入学习模式（语音触发）
- [ ] 31. 说「今天天气怎么样」 — 预期：走普通闲聊，不误进学习模式
- [ ] 32. 说「帮我打开浏览器」 — 预期：正常执行操作，不误进学习模式
