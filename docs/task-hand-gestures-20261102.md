## 行为

- 思考：摸下巴与挠头交替，每次短动作后回位，同状态至少间隔十秒。
- 真正执行工具：点头；等待：张望；完成：轻回应；失败：摇头。
- 普通问答等待回答时也进入思考状态，第一段回答到达即结束；极短请求不足 1.2 秒不闪动作。
- 用真实任务/工具事件驱动，定时器不生成进度，不额外调用模型。
- 说话、唱歌、拖动、困倦优先；停止/取消/失败不触发成功庆祝；并行任务仍在运行时不提前宣布完成。
- 新手部动作可从右键「音乐与动作 → 摸下巴思考 / 挠挠头」点播，也可由语音 perform_gesture 和 pet_control 调用。
