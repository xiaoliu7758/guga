# 咕嘎多智能体（2026-10-29，形象迭代 .6）

## 当前成员

- 001 咕嘎：原画、原声音与既有任务能力保留，常规启动时唯一出现。
- 002 大肥鱼：使用用户指定目录中的蓝发女仆角色，技术审查员。
- 003 Dora：使用用户本轮提供的高清粉发橘子角色，橘子创意搭档。

右键咕嘎的“多智能体”菜单或说“召唤大肥鱼”“叫出Dora”“叫出两个咕嘎”，创建对应的独立轻量窗口。三位成员共用一个主进程和执行工具，不创建重复托盘、全局快捷键或麦克风。

## 独立身份与共同能力

各成员有独立编号、角色、擅长、长期记忆、对话历史和当前会话。切换成员后，侧栏、模型上下文、任务结果气泡都按成员隔离。002 和 003 同样拥有底层问答、电脑、文件、DSH 和音乐工具；本轮没有替换模型、API 配置和任务执行架构。

长期记忆在 runtime/multiagent/memory.sqlite3；会话在 runtime/chat/workspace.sqlite3。写入记忆前脱敏，不保存 API Key。团队讨论只交换公开发言，不共享私有记忆。

## 新形象与真实表情

Dora 有吃橘子/开心、委屈哭泣、生气、困倦 4 张高清透明素材；大肥鱼有指点/日常、开心、委屈、困倦坐姿 4 张素材。

所有贴图为真正 RGBA，超过 1200 像素，保留脸、发型、服装和完整身体。原图缺失的足部由图像编辑补全。Dora 困倦为本轮派生。三张近似重复的生气图仅计一份。

manifest.json 明确记录运行素材与兼容状态，缺少专用贴图的状态使用已注明的近似贴图，不冒充新表情。来源详情见 resources/multiagent/dora/SOURCE.md 与 dafish/SOURCE.md。旧图均保留。

## 动作与交互

- 约 30 帧/秒、基于时间的呼吸轻摆和落地阴影，不随帧率改变速度。
- 鼠标靠近时偶尔关注 2—4 秒，再自然归位；有冷却，困倦时不跟随。
- 拖动有轻微惯性倾斜，松开后回正；位置保存，各窗口分别操纵。
- 支持弹跳、暗中观察、点头、歪头、摇头和轻转身。只使用前视原画，避免把图倒转、压成纸片或造假背面。
- 右键“切换表情”直接切换对应 PNG；对话工具也路由到当前成员的表情。
- 困倦一直保持，后台回复、动作和鼠标关注不唤醒；用户发消息、主动说话或点击互动才恢复开心。
- 表情切换短暂交叠，窗口大小固定，动作有预留边距。

这是保留原画的 2.5D 动态，尚不是带骨骼、背面和独立发丝的真正三维模型。坐姿与站姿保留原素材的区别。

## 团队讨论与主动交流

两位或三位成员可以按各自角色与记忆讨论同一主题。讨论副本不调用工具，讨论结论不会自动转成操作。用户仍可把明确任务交给当前成员执行。

通话空闲时，现有主动交流机制可从该成员记忆选择话题；任务执行、用户说话、播放回答/歌曲或未连接时不主动开口。本轮未自动开启麦克风或消耗 API 做外部讨论验收。
