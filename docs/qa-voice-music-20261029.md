# 问答、短语音与唱歌迭代（2026-10-29.3）

**后续更正：本版划词焦点方案未通过用户实际验收，已由 [2026-10-29.4 的选区画面缓存路径](selection-visual-fix-20261029.md) 替换。** 下文保留本版其他功能及历史验证记录。

## 用户可见操作

- 左键选词后点击「解释／翻译」。修正 Windows 点击工具条时的激活处理；只有明确点了工具条，才允许恢复到记录的原选词窗口进行复制。普通调用不会把焦点从其他软件拉走。复制仍检查目标窗口、剪贴板变化及来源进程，恢复旧剪贴板，不把旧内容冒充选区。
- 「说话」：点一次开始录音，说完再点一次；最多 30 秒。原 Vosk 离线识别 → DeepSeek 的咕嘎人格回答 → 原 Edge TTS 朗读。识别和录音停止在后台进行，语音不写入磁盘；未加声纹识别。Edge TTS 是发声引擎，不承担语音识别。
- 「通话」：原千问端到端实时通话，保留任务交接、气泡、打断及现有配置。与短语音互斥，避免争抢麦克风。
- 普通问答和截图有「快速／轻度／高／极限」档位，分别对应关闭思考、low、high、max。默认快速；只显示回答正文，不显示隐藏推理。答案流式出现，不等待整条回答生成完。
- 「自动分流」下，普通问题走无工具问答，明确电脑操作继续走原任务执行器。另可手动选「只问答」或「执行任务」。问答不启用任务规划、12 秒进度汇报或任务日志；执行任务的策略不受问答档位影响。
- 截图仍然一键发送到当前对话，默认快速回答。当前任务忙碌时保留附件，不打断或混入另一个任务。
- 《晴天》使用原有翻唱音频单曲循环，取消 75 秒自动暂停。说「停止唱歌」、点浮窗「停止」或桌宠右键停止唱歌会停止循环。手动暂停／继续仍可用。其他歌曲沿用原行为；退出软件或音频错误也会结束播放，不做无限错误重试。
- 扬声器播放歌曲时，云端输入仍保持原防回声处理；已有通话的麦克风原始数据会额外交给本机 Vosk，只匹配停止唱歌口令，不发往云端、不保存录音。语音停止的识别率受麦克风和音乐音量影响，始终保留按钮停止。

## 原因与修正

上版把选词来源窗口和点击时的前台窗口做了严格相等判断。工具条的鼠标激活或其他软件划词条造成的焦点变化也会触发拒绝，出现「原选词窗口已切换」。现在增加 WM_MOUSEACTIVATE 的 MA_NOACTIVATE 处理，以及显式点击后的原窗口恢复；没有取消复制前的目标校验。

原来所有非快捷消息都进入 SelfAgent，默认高思考、工具调用和任务循环。新增 core/chat_answer.py 独立处理问答，没有 tools 字段，也不创建任务目录。用与当前配置相同的模型服务，按档位发送真实参数；Go 路径的快速档额外传 reasoning_effort=none，而非只在界面隐藏思考。

原音乐播放器每次播放会启动 75000 毫秒定时器并暂停。晴天现改为 QMediaPlaylist.CurrentItemInLoop，并停用这项自动暂停。

同时修正语音启动后 120 毫秒的延迟动作：它不能覆盖已经出现的快速语音回答，也不能把用户点气泡展开的窗口重新隐藏。

## 验证范围

- 86 项离线回归通过，覆盖问答独立请求、四档参数、流式正文、取消、短语音、截图、复制前校验、剪贴板恢复、音乐、语音工具交接和原实时语音路径。
- 原语音与气泡实控件冒烟通过。
- 原生自建 Qt 窗口选词测试通过，验证选区读取、不抢焦点和剪贴板恢复；没有冒称逐个验收所有第三方软件。
- 实际 Go 模型调用仅使用合成测试图片和数学问题：快速截图回答「3, 5」，首段约 2.89 秒、总计 3.14 秒，服务端 reasoning_tokens=0；轻度回答「9.8」，服务端 reasoning_tokens=80。费用源为已有 Go 套餐；未切换到额外付费服务。高和极限只做参数回归，未消耗长推理测试额度。
- Windows 原生播放器静音测试：自建 0.4 秒 WAV 连续循环两次，随后成功停止。未在后台持续播放测试音频。
- 未替用户录制真实麦克风样本；短语音听感和嘈杂环境下的停止口令仍需用户实际使用验证。
- 本地运行版已重启并由应用自身确认版本 2026-10-29.3，自动分流／快速档为当前默认值，外部选词监听与两个快捷键正常，管理员和完整访问权限保持，启动错误日志为空。当前没有自动播放歌曲或后台测试。
