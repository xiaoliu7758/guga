## 修复：智能体「看不到屏幕」问题（对话内直接生成思维导图）

### 修复
- `core/self_agent.py` — TOOLS 新增 `study` 工具（action: mindmap/expand/quiz/cards/package）
- `ui/agent_runtime.py` — `execute()` 注册 `study` 分发；新增 `_study()`（截图→study_package）；capabilities 加 `study`
- `core/execution_contract.py` — ACTION_WORDS 补学习动作词（生成/思维导图/提炼/知识点/出题/自测/复习卡/导图等）

### 验证

## 修复长回答朗读「念不全」+ 自动存文档

### 根因
tts_engine.speak() 把整段长文本一次性交给 edge-tts 合成，edge-tts 单次有长度上限(约300-500字)，超出被截断。

### 修复
- `ui/tts_engine.py` — speak() 改为分段朗读：
  - _split_segments() 按句末标点切分、贪心合并，每段≤280字
  - _play_segment() 逐段合成播放；_on_state_changed 一段播完自动续播下一段
  - _stop_playback() 清空分段队列；新增 _segments/_seg_index/_voice_profile 状态
- `ui/agent_chat.py` — 长回答自动存文档：
  - 朗读开启时回答超长 → 自动后台保存 .md + 思维导图(不弹窗打断)，气泡提示「全文已保存」
  - 朗读关闭时 → 保留原手动弹窗询问
  - 新增 _export_done 信号 + _auto_export_worker + _on_export_done

### 关键约定
